A GTA 6 meme generator: main.ts draws "Florida Man Was Born Ready" — the make.fun ghost as a Florida Man on a Vice City beach — as a deterministic 1080x1080 PNG with the Node standard library alone, and copies POST.json to the output directory. POST.json names the X post (placeholder until the meme is posted).

## Run it

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
